Usage: floci gcp env [-hqvV] [--no-color] [--container=<name>] [--endpoint=<url>]
                     [-o=text|json|yaml] [--profile=<name>] [--service=<csv>] [--shell=<shell>]
Print GCP environment variables to connect to Floci GCP
      --container=<name>   Floci container name (default: floci-gcp)
      --endpoint=<url>     Floci server endpoint URL (default: http://localhost:4588)
  -h, --help               Show this help message and exit.
      --no-color           Disable ANSI colors
  -o, --output=text|json|yaml
                           Output format: text, json, yaml
      --profile=<name>     Config profile from ~/.floci/profiles/
  -q, --quiet              Suppress non-error output
      --service=<csv>      Comma-separated services: gcs,pubsub,firestore,datastore,secretmanager,
                             iam
      --shell=<shell>      Shell format: bash, zsh, sh, fish, powershell (default: bash)
  -v, --verbose            Debug logging to stderr
  -V, --version            Print version information and exit.
