Usage: floci gcp wait [-hqvV] [--json] [--no-color] [--no-emoji] [--container=<name>]
                      [--endpoint=<url>] [-o=text|json|yaml] [--profile=<name>] [--service=<name>]
                      [--timeout=<duration>]
Wait until Floci GCP is ready to accept requests
      --container=<name>     Floci container name (default: floci-gcp)
      --endpoint=<url>       Floci server endpoint URL (default: http://localhost:4588)
  -h, --help                 Show this help message and exit.
      --json                 Shorthand for --output json
      --no-color             Disable ANSI colors
      --no-emoji             Plain ASCII marks instead of Unicode ones (the default when output is
                               piped)
  -o, --output=text|json|yaml
                             Output format: text, json, yaml
      --profile=<name>       Config profile from ~/.floci/profiles/
  -q, --quiet                Suppress non-error output
      --service=<name>       Wait until a specific service is enabled
      --timeout=<duration>   Maximum time to wait (e.g. 30s, 2m)
  -v, --verbose              Debug logging to stderr
  -V, --version              Print version information and exit.
