Usage: floci az snapshot import [-hqvV] [--json] [--no-color] [--no-emoji] [--container=<name>]
                                [--endpoint=<url>] -f=<path> [--name=<name>] [-o=text|json|yaml]
                                [--profile=<name>]
Import a Floci Azure snapshot from a tarball file
      --container=<name>   Floci container name (default: floci-az)
      --endpoint=<url>     Floci server endpoint URL (default: http://localhost:4577)
  -f, --file=<path>        Source tarball path
  -h, --help               Show this help message and exit.
      --json               Shorthand for --output json
      --name=<name>        Name for the imported snapshot
      --no-color           Disable ANSI colors
      --no-emoji           Plain ASCII marks instead of Unicode ones (the default when output is
                             piped)
  -o, --output=text|json|yaml
                           Output format: text, json, yaml
      --profile=<name>     Config profile from ~/.floci/profiles/
  -q, --quiet              Suppress non-error output
  -v, --verbose            Debug logging to stderr
  -V, --version            Print version information and exit.
